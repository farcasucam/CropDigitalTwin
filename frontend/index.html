      Record / replay session

      A session stores the configuration, event sequence, seed, checkpoints and hashes (not a screenshot). Replay re-runs the backend and checks that events, checkpoints, trajectory hashes and the final state are reproduced.

      Playback is presentation only: it never changes the simulation. The plot is shown as a lumped canopy; no per-plant state is created.
